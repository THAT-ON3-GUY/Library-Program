# Overview


I wrote this Library program to help myself learn more about the C# language. 
For this program my objective was to create a library system that allowed me to provide the program a formatted J
SON file of books I've read including their titles, authors, year of publication, and whether or not I've read them.
I also wanted to allow the user to display the full list of books, search for a book, add a book to the library,
update a books information, save changes you've made to the JSON file, and quit out of the program.

I also wrote this software because it will help me better organize my personal 
collection of books and decide what to read next.
